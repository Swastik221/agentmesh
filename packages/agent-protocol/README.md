# AgentMesh Protocol (`@agentmesh/agent-protocol`)

AgentMesh Protocol will define structured communication between AI agents.

## Message Types

Future protocol messages will include:

- `HELLO`
- `CAPABILITY_ANNOUNCEMENT`
- `TASK_PROPOSAL`
- `TASK_CLAIM`
- `TASK_COMPLETE`
- `DEPENDENCY_REQUEST`
- `DEPENDENCY_RESPONSE`
- `ARTIFACT_PUBLISHED`
- `BUG_REPORT`
- `TEST_STARTED`
- `TEST_RESULT`
- `APPROVAL_REQUEST`
- `PAYMENT_REQUEST`
